# Lakou Haiti - local asset inventory and credits

## Scope and provenance

Earlier asset passes changed only image assets and this inventory. Two later passes also changed code. The Colora prototype update added a gallery to the detail panel. The simplification pass restructured the homepage below the statistics strip into two groups of clickable summaries, whose details open in the existing detail panel. The first group is Problem → Solution. The second is the Explore cards: About, Integrated Model, Colora Prototype, Réalisations à Lakou Colora and Partners. The hero, header, statistics strip, program grid, translations and program interactions are unchanged. Existing JPG pixel dimensions and filenames are preserved, except `prototype.jpg`, which now uses the map's native resolution.

Photographs are contextual illustrations of Haiti, not proof of Lakou Haiti activities, achievements, ownership, endorsements, or partnerships. Archival photographs are not presented as current project documentation. No statistics or partnership claims were added.
